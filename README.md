# VegaChat — сборка Android-приложения через GitHub Actions

Никакого компьютера с Android Studio не нужно — GitHub сам соберёт APK
в облаке. Инструкция ниже — прямо с телефона.

## Шаг 1. Создай репозиторий на GitHub

1. Зайди на https://github.com, зарегистрируйся, если ещё нет аккаунта
2. Нажми **"+"** в правом верхнем углу → **"New repository"**
3. Название — любое, например `vegachat-app`
4. Оставь **Public** (или Private — без разницы)
5. Не ставь галочку "Add a README" — она нам не нужна, у нас свой
6. Нажми **"Create repository"**

## Шаг 2. Загрузи файлы

1. На странице пустого репозитория нажми **"uploading an existing file"**
   (ссылка прямо на странице) или **"Add file" → "Upload files"**
2. Перетащи/выбери файлы из этого архива — **все**, включая скрытую
   папку `.github` (на телефоне может понадобиться распаковать zip
   файловым менеджером, который показывает скрытые/системные папки —
   папки начинающиеся на точку иногда прячутся)
3. **Важно про структуру папок:** GitHub веб-загрузка может не сохранить
   вложенность `.github/workflows/build-apk.yml`. Если после загрузки
   этого файла не видно по такому пути — создай его вручную:
   - "Add file" → "Create new file"
   - В поле имени файла впиши **целиком**: `.github/workflows/build-apk.yml`
     (слэши сами создадут нужные папки)
   - Скопируй туда содержимое файла `build-apk.yml` из этого архива
   - Нажми "Commit new file"
4. Так же проверь, что `www/index.html`, `www/icons/...`, `package.json`,
   `capacitor.config.json` загрузились и лежат на правильных путях

## Шаг 3. Запусти сборку

1. Открой вкладку **"Actions"** в репозитории
2. Слева выбери **"Build Android APK"**
3. Справа нажми **"Run workflow"** → **"Run workflow"** (кнопка появится,
   если workflow подхватился — если её нет, убедись что файл лежит
   именно по пути `.github/workflows/build-apk.yml`)
4. Подожди 3-5 минут — статус сборки будет виден тут же (жёлтый кружок →
   зелёная галочка)

## Шаг 4. Скачай APK

1. Открой завершённый прогон (зелёная галочка) в списке
2. Внизу страницы — раздел **"Artifacts"**
3. Скачай **vegachat-debug-apk** — это zip с файлом `app-debug.apk` внутри
4. Перекинь APK на телефон и установи (разреши "Установка из
   неизвестных источников", если попросит)

## Что дальше

- Ссылка на бота теперь открывается через `@capacitor/browser` — это
  системный браузер (Chrome Custom Tabs), а не встроенный WebView, так
  что `tg://` сработает штатно и откроет Telegram.
- Значок приложения — сгенерированный по умолчанию Capacitor. Захочешь
  поменять — напиши, подскажу как заменить иконки в
  `android/app/src/main/res/mipmap-*` (это уже надо будет делать локально
  или отдельным шагом в workflow).
- Это **debug**-сборка — этого достаточно, чтобы установить и
  пользоваться самому. Для публикации в Google Play нужна отдельная
  подписанная (release) сборка — скажи, если дойдёт до этого, добавлю
  шаг подписи в workflow.
